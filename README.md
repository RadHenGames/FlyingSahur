# Flying Sahur — GitHub Pages Site

Game page for [Flying Sahur](https://funkymonkeyhen.github.io/flying-sahur/) by Rad Hen Games.

## Repo Structure

```
flying-sahur/
├── index.html        ← wrapper page with ad slots
├── deploy.sh         ← copies Godot export into /game
├── game/             ← Godot HTML5 export (auto-generated by deploy.sh)
│   ├── index.html
│   ├── index.js
│   ├── index.wasm
│   ├── index.pck
│   └── ...
└── README.md
```

## Deploying a New Build

1. Export your game from Godot: **Project → Export → HTML5**
2. Edit `deploy.sh` and set `GODOT_EXPORT_DIR` to your export folder
3. Run:
   ```bash
   chmod +x deploy.sh
   ./deploy.sh
   ```
4. Push to GitHub — Pages auto-deploys from `main` branch

## AdSense Setup (when approved)

1. Get your publisher ID from [adsense.google.com](https://adsense.google.com) (`ca-pub-XXXXXXXXXXXXXXXX`)
2. In `index.html`:
   - Uncomment the `<script async src="https://pagead2...">` tag in `<head>` and replace the publisher ID
   - Replace each `<div class="ad-placeholder ...">` block with the real `<ins class="adsbygoogle" ...>` ad unit code from your AdSense dashboard
3. Push the update

## Local Testing

```bash
cd /path/to/flying-sahur
python3 -m http.server 8080
# Open http://localhost:8080
```

## GitHub Pages Setup (one-time)

1. Create a new repo named `flying-sahur` under your GitHub account
2. Push this folder to it
3. Go to **Settings → Pages → Source → Deploy from branch → main / (root)**
4. Your site will be live at `https://funkymonkeyhen.github.io/flying-sahur/`
